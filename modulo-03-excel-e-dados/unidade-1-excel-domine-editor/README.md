# ❀ Excel: Domine o Editor de Planilhas

Este curso faz parte do **Módulo 3 da Open Academy — Dados com IA (Alura)**.  
Aqui desenvolvi as bases do uso do Excel para organização, análise e visualização de dados.

---

## ❀ Objetivo do Curso

Desenvolver fundamentos sólidos no Excel para:
- Estruturação de planilhas
- Cálculos básicos
- Organização financeira
- Visualização de dados
- Resolução de erros em fórmulas

---

## ❀ Conteúdos Aprendidos

- O que é uma planilha e uma pasta de trabalho  
- Funcionalidades básicas do Microsoft Excel  
- Cálculos simples em planilhas  
- Introdução a gráficos  
- Compartilhamento e impressão de pasta de trabalho  

---

### ✿ 4. Ajustando o valor de desconto (#REF!)

**Objetivo:**  
Corrigir erros do tipo **#REF!** gerados após exclusão de células referenciadas.

**Problema:**  
A exclusão de células causou erro nas fórmulas relacionadas ao cálculo de desconto.

**Solução:**  
- Readequação das fórmulas  
- Correção das referências  

**Resultado:**  
![ajustando o valor de desconto](assets/ajustandoOValor.png)

**O que aprendi:**  
- Como ocorrem erros #REF!  
- Como recuperar fórmulas quebradas
